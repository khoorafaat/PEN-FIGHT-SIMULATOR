# Contributing

Thanks for considering a contribution.

## Before you start

- Search existing issues to avoid duplicates.
- For a substantial change, open an issue first to discuss the approach.
- Keep pull requests focused and explain the user-visible impact.

## Pull request checklist

- [ ] The change has been tested in a current browser.
- [ ] Existing game modes and controls still work.
- [ ] No unrelated files or generated artifacts are included.
- [ ] Documentation is updated when behavior or setup changes.
- [ ] No secrets, credentials, or private user data are committed.

## Code style

The project currently uses dependency-free vanilla JavaScript and CSS. Follow the existing style in the file you are editing, use descriptive names, and add comments for non-obvious physics or state transitions.
