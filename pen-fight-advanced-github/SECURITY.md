# Security policy

## Supported versions

The latest version on the default branch is the only version currently supported.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Contact the repository maintainer privately through GitHub and include:

- A description of the issue and its potential impact
- Steps to reproduce
- A suggested mitigation, if known

This is a static browser game and currently does not process accounts, payments, or server-side user data. Please still report issues involving unsafe content handling, dependency supply-chain risks, or deployment configuration.
