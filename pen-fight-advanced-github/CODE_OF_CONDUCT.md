# Contributor Covenant Code of Conduct

## Our pledge

We are committed to making participation in this project a welcoming and respectful experience for everyone.

## Expected behavior

- Be respectful and considerate.
- Give and accept constructive feedback.
- Focus on what is best for the project and its community.
- Respect differing viewpoints and experiences.

## Unacceptable behavior

Harassment, discrimination, personal attacks, intimidation, and publishing others' private information without permission are not acceptable.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. Report conduct concerns privately to the repository maintainer using the contact method listed on the GitHub repository. If no contact method is listed, open a private communication through GitHub where available.
